# AGENTS.md

## Project

Expedia Lite is an IST 402 travel application.

## Part 1 goal

Implement hotel-name search using the supplied CSV files.

## Frontend

- Vue
- Search input and Search button
- Display matching hotels and available stays
- Show a no-results message when nothing matches

## Backend

- Python
- FastAPI
- Read `hotels.csv` and `trips.csv`
- Connect hotel and trip records using `hotel_id`

## Development notes

Keep the frontend in `frontend/` and backend in `backend/`.

Part 2 will add SQLite and booking CRUD functionality.
