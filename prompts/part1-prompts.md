# Part 1 Selected Prompts

## Prompt 1

Create a FastAPI backend for a travel application that reads `hotels.csv` and `trips.csv`, searches hotels by hotel name, and connects matching trip records using `hotel_id`.

## Prompt 2

Create a Vue frontend with a hotel-name search box and Search button. Display matching hotel information and available stays in a table.

## Prompt 3

Show a clear message when a hotel search returns no matching results.

## Prompt 4

Keep the Vue frontend in `frontend/` and the Python/FastAPI backend in `backend/`.
